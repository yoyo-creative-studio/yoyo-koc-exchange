# Repository Working Rules

## Required Delivery Workflow

- After completing and validating any requested code or content change, commit the relevant files and push the commit to `origin/main` in the same turn.
- Do not leave completed changes only in the local working tree unless the user explicitly says not to push.
- Confirm that the remote `main` branch contains the new commit before reporting completion.
- Do not include unrelated modified or untracked files in the commit.
- If pushing fails, report the exact blocker and keep retrying reasonable recovery steps before returning to the user.
